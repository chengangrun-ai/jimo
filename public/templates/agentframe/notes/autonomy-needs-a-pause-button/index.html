PERSPECTIVES/5 MIN READ

Good autonomy needs a pause button

Useful autonomy is a matter of judgment. The question is not whether an agent can act, but which decisions it should be able to make on its own.

Start with the consequences

Reading a document and publishing a document are different actions, even if the same tool can do both. Define permissions around their consequences. Give the agent room to gather context and prepare work while making publication a deliberate decision.

Ask at the last responsible moment

An approval request is most useful when it includes something concrete to review. Let the agent do the research, assemble the change, and explain the effect. Then ask the person who owns that decision.

Make waiting a valid state

A paused run is not a failed run. Preserve the proposed action and the context behind it so that approval can arrive later. The agent should continue from that decision without redoing the work that made it reviewable.

A clear boundary creates room

When the boundary is explicit, the agent can act confidently inside it. That is the point of a useful harness: to make progress easier to trust, understand, and resume.

Good agents need a good place to work.
